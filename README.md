## Prerequisites

Make sure you have Python installed, then install the required dependencies:

```bash
pip install opencv-python numpy
```

## Assets Required

Place the following files in the same directory as the script:
- `badApple.mp4` (Source video)
- `Takeshi_Exp.png` (Blonde hair variant for highlight/white areas)
- `Normal_Exp.png` (Bald variant for shadow/black areas)
